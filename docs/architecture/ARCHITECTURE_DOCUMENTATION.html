Executive Summary

Greyin is a self-hosted, production-grade B2B/B2C platform ecosystem serving senior professionals (12+ years experience) with verified expertise tracking, peer collaboration, and skill-based marketplaces. The platform unifies six pillar applications under a single authentication system, shared reputation score, and cross-pillar activity tracking.

Core Positioning

  • Target User: Senior domain professionals, verified experts, enterprise hiring teams
  • Revenue Model: B2B hiring subscriptions (DeepEdge), freelance platform fees (FlexPro), outplacement/coaching (enterprise), future hiring pipeline (Longlist)
  • Differentiation: Real verified expertise (StackWorks/FlexPro verified outcomes), Greyin Score (unified reputation), senior-only peer community (Salt & Pepper)

4.2 Greyin Score Algorithm

def calculate_greyin_score(user_id): # 1. Per-platform evidence collection stackworks_outcomes = get_verified_outcomes(user_id, 'stackworks') flexpro_completions = get_order_completions(user_id, 'flexpro') saltnpepper_karma = get_discussion_karma(user_id) greymatters_posts = count_published_posts(user_id) # 2. Bayesian shrinkage (pull outliers toward mean) stackworks_score = shrink_toward_mean( observed_mean = mean(stackworks_outcomes.scores), population_mean = 40, n = len(stackworks_outcomes), precision = 10 # Higher = stronger shrinkage ) # 3. Headcount weighting (more evidence = more weight) scores_by_platform = { 'stackworks': (stackworks_score, len(stackworks_outcomes)), 'flexpro': (flexpro_score, len(flexpro_completions)), 'saltnpepper': (saltnpepper_score, 1), 'greymatters': (greymatters_score, 1) } # Weighted average with evidence counts platform_composite = weighted_mean( [(score, min(count, 5)) for score, count in scores_by_platform.values()] ) # 4. Add career experience (15% weight) years_exp = get_years_experience(user_id) experience_term = (years_exp / 30) * 100 greyin_score = (0.85 * platform_composite) + (0.15 * experience_term) return max(0, min(100, int(greyin_score)))

4.3 Job Recommendation Engine

Algorithm: Candidate embeddings → Job embeddings → k-NN ranking → exclude downvotes → diversity reweighting

Step Computation Latency
1. Encode candidate Skills + role history → vector embedding <100ms
2. Encode open jobs Job title + description → vectors <500ms (batch)
3. k-NN ranking Cosine similarity on embeddings <50ms
4. Exclusion filter Remove recently downvoted jobs <10ms
5. Diversity reweight If 3+ downvotes, favor different roles/companies <50ms

4.4 Outcome Verification (StackWorks)

Process:
  1. Supporter submits ask completion with summary
  2. Project creator reviews + LLM evaluates:
    • Fetch linked GitHub repo
    • Look for recent commits matching description
    • Score implementation quality (50-100 scale)
  3. Creator provides human score
  4. Average of LLM + human score stored
  5. Score feeds into Greyin Score (30% platform weight)
